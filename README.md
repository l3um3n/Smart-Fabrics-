# Smart-Fabrics-
Smart Fabrics is a wearable technology project focused on developing clothing that can sense and interpret human movement through embedded flexible pressure sensors. The core prototype uses an Arduino Nano and an array of 11 Velostat-based sensing regions positioned across areas including the pectorals, biceps, shoulders, upper traps, mid-back, abdominals, and lower back. The system collects changes in electrical resistance caused by movement and pressure, then uses calibration and data processing to map activity across different regions of the body. The project explores identifying left/right movement and distinguishing contraction patterns such as isometric, concentric, and eccentric motion. Alongside the electronic system, the project investigates alternative conductive and pressure-sensitive materials and different sensor geometries to improve sensitivity, reduce saturation, and create flexible sensors suitable for integration directly into clothing. The long-term goal is to develop a minimal, responsive garment that can translate physical movement into meaningful digital information while maintaining the functionality and appearance of everyday clothing.
